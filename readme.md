# 📚 Тренажёр ЭМО

Интерактивный образовательный тренажёр для обучения чтению и письму.

## 📋 Описание

Тренажёр с мягкой женской озвучкой, где нужно правильно напечатать слово по изображению. Разработан специально для детей с особенностями развития. **Принимает любой ответ** (даже с ошибками) для выявления проблем в обучении.

## ✨ Возможности

- 🎧 **Мягкая женская озвучка** всех заданий и результатов
- ⌨️ **Ввод текста** - печатай ответ самостоятельно
- ✅ **Принимает любой ответ** - даже с ошибками (для анализа)
- 🟢 **Зелёная галочка** - когда начинаешь печатать
- 🗣️ **"Ваш ответ принят, идём дальше"** - после каждого ответа
- 🎨 **Яркий дизайн** в фирменных цветах ЭМО (#00D4E8)
- 📊 **Цветовая маркировка** - гласные красные, согласные чёрные
- 📱 **Адаптивность** от 1200px до 4K
- 💾 **Автосохранение** прогресса в браузере
- 🔄 **Автопереход** к следующему вопросу

## 📦 Установка

### Структура файлов:

```
/
├── question.html           # Главная страница с вопросами
├── answers.html            # Страница с результатами
├── styles.css              # Все стили (общие)
├── images/                 # Папка с изображениями

│   ├── 2-ashan.jpg        # Ашан
│   ├── 3-tyumen.jpg       # Тюмень
│   ├── 4-katok-road.jpg   # Каток дорожный
│   └── 5-katok-ice.jpg    # Каток ледовый
```

### Вариант 1: Локальное использование

1. Создайте папку `trainer`
2. Скопируйте туда файлы: `question.html`, `answers.html`, `styles.css`
3. Создайте подпапку `images`
4. Поместите 5 изображений в папку `images` с точными названиями:
   - `1-zeleni.jpg`
   - `2-ashan.jpg`
   - `3-tyumen.jpg`
   - `4-katok-road.jpg`
   - `5-katok-ice.jpg`
5. Откройте `question.html` в браузере (Chrome или Edge)

### Вариант 2: Размещение на сайте

1. Загрузите все файлы на хостинг с сохранением структуры папок
2. Убедитесь что пути работают:
   ```
   https://ваш-сайт.ru/question.html
   https://ваш-сайт.ru/answers.html
   https://ваш-сайт.ru/styles.css
   https://ваш-сайт.ru/images/1-zeleni.jpg
   ```
3. Откройте question.html

### Вариант 3: GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы (с папкой images)
3. Settings → Pages → выберите main branch
4. Сайт: `https://username.github.io/repo-name/question.html`

## 🎮 Как использовать

### Для учеников:

1. **Главная страница (question.html):**
   - Нажмите 🎧 чтобы включить/выключить звук (жёлтая = включён)
   - Посмотрите на изображение
   - Напечатайте ответ ЗАГЛАВНЫМИ буквами
   - Галочка ✔ становится **ЗЕЛЁНОЙ** когда вы начали печатать
   - Нажмите ✔ или Enter

2. **Прохождение:**
   - **Любой ответ принимается** - даже с ошибками!
   - Голос скажет: "Ваш ответ принят, идём дальше"
   - Автоматический переход к следующему вопросу (1.5 сек)
   - Боковая панель: розовый = текущий, зелёный с ✓ = пройденный

3. **Результаты (answers.html):**
   - Таблица показывает ВСЕ ответы (правильные и неправильные)
   - Гласные буквы - **красные**, согласные - **чёрные**
   - ✅ = правильно, ❌ = неправильно
   - Эмодзи в зависимости от результата
   - Кнопка "ПРОЙТИ ТЕСТ ЗАНОВО"

### Для преподавателей:

- **Важно!** Тренажёр принимает любой ответ (даже с ошибками)
- Это сделано специально для выявления проблем в обучении
- В таблице результатов видны все ошибки ученика
- Можно анализировать какие буквы путает ребёнок
- Крестик ✕ в правом нижнем углу - выход с очисткой данных

## 🔧 Настройка

### Как добавить новые вопросы:

В `question.html` найдите массив `QUESTIONS`:

```javascript
const QUESTIONS = [
  { 
    id: 6,  // новый номер
    label: 'НАПЕЧАТАЙ: МОСКВА', 
    img: 'images/6-moskva.jpg',  // путь к изображению
    correct: 'МОСКВА',  // правильный ответ
    voiceText: 'Напечатай: москва'  // текст для озвучки
  },
  // ... добавьте сколько нужно
];
```

**Важно:**
- Изображение должно быть в папке `images/`
- Название файла: `номер-название.jpg`
- `correct` пишите ЗАГЛАВНЫМИ буквами

### Как изменить цвета:

В `styles.css` в блоке `:root`:

```css
:root{
  --bg-page: #00D4E8;          /* фон страницы */
  --accent-yellow: #FFD700;     /* жёлтая кнопка */
  --vowels-color: #d01818;      /* цвет гласных */
  --consonant-color: #0b0b0b;   /* цвет согласных */
}
```

### Как настроить озвучку:

В функции `speak()`:

```javascript
utterance.rate = 0.85;   // скорость (0.1 - 10)
utterance.pitch = 1.3;   // высота голоса (0 - 2)
utterance.volume = 1.0;  // громкость (0 - 1)
```

## 🎯 Ключевые особенности

### ✅ Принимает любой ответ
Тренажёр **специально** принимает любой ответ, даже с ошибками. Это сделано для:
- Выявления проблем в обучении
- Анализа ошибок ученика
- Понимания какие буквы путает ребёнок
- Отслеживания прогресса

### 🟢 Зелёная галочка
Когда ученик начинает печатать, галочка ✔ становится **зелёной**:
- Визуальная обратная связь
- Показывает что ответ готов к отправке
- Помогает детям понять когда можно нажимать

### 🗣️ Озвучка действий
- "Привет! Напечатай правильные ответы!"
- Озвучка каждого задания
- "Ваш ответ принят, идём дальше"
- Озвучка итогов

## 🐛 Известные особенности

- Озвучка может отличаться в разных браузерах
- На iOS озвучка работает только после действия пользователя
- Если изображение не найдено - показывается плейсхолдер
- LocalStorage очищается при очистке данных браузера

## 📊 Методические рекомендации

### Для преподавателей:

1. **Перед началом:**
   - Покажите как работает звук 🎧
   - Объясните что нужно печатать заглавными
   - Покажите что галочка становится зелёной

2. **Во время прохождения:**
   - Не исправляйте ошибки сразу
   - Пусть ребёнок напечатает как слышит/видит
   - Наблюдайте за процессом

3. **После прохождения:**
   - Откройте таблицу результатов
   - Покажите правильные ответы (красные/чёрные буквы)
   - Разберите ошибки
   - Обратите внимание на паттерны ошибок

4. **Анализ результатов:**
   - Какие буквы чаще всего путает?
   - Есть ли проблемы с гласными/согласными?
   - Нужна ли дополнительная работа?

## 🔒 Безопасность и приватность

- Все данные хранятся **только** в браузере ученика
- Никакая информация не отправляется на сервер
- При закрытии браузера данные могут быть удалены
- Кнопка выхода ✕ очищает все данные
