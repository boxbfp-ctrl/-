# Тренажер ЭМО

Интерактивный тренажер для развития прикладных навыков, созданный в рамках тестового задания на позицию Web-программиста.

## 📋 Описание проекта

Тренажер представляет собой веб-приложение для обучения распознаванию объектов на изображениях. Пользователь видит картинку и должен ввести правильный ответ. После прохождения всех вопросов отображается таблица с результатами.

## 🎯 Функциональность

- **Страница с вопросом** (`question.html`) - отображает изображение и поле для ввода ответа
- **Страница с результатами** (`results.html`) - показывает таблицу с правильными и неправильными ответами
- **Галерея изображений** - превью всех вопросов в верхней части страницы
- **Индикатор прогресса** - нумерованные кружки показывают текущий вопрос
- **Интерактивность** - кнопка активируется при вводе текста, поддержка Enter для отправки

## 🛠 Технологии

- **HTML5** - семантическая разметка
- **CSS3** - стилизация с использованием Flexbox и Grid
- **JavaScript (Vanilla)** - базовая интерактивность

## 🎨 Особенности верстки

### Адаптивность
Верстка корректно отображается на разрешениях от 1200px до 4K (3840px):
- **< 1200px** - уменьшенные элементы
- **1200-1400px** - базовый размер
- **1400-1920px** - увеличенные элементы
- **1920px+** - максимальные размеры для 4K экранов

### Переиспользуемые классы
- `.panel-outer` / `.panel-inner` - обертки для панелей
- `.table-cell` - базовая ячейка таблицы
- `.table-cell--number` / `.table-cell--answer` - модификаторы ячеек (BEM)
- `.is-active` / `.is-correct` / `.is-incorrect` - состояния элементов
- `.result-icon` - иконки результатов

### Цветовая схема
- **Фон** - темно-серый (#1f2937)
- **Панель вопроса** - голубой (#22d3ee)
- **Активный элемент** - фиолетовый (#9333ea)
- **Правильный ответ** - зеленый (#22c55e)
- **Неправильный ответ** - красный (#ef4444)

## 💻 Запуск проекта

1. Откройте файл `question.html` в браузере
2. Введите ответ на вопрос и нажмите кнопку ✓ или Enter
3. Перейдите на страницу результатов через ссылку внизу
4. На странице результатов можно вернуться к вопросам или начать заново

## ✅ Соответствие требованиям

### Верстка
- ✅ Реализована на HTML/CSS
- ✅ Два HTML файла (вопрос и результаты)
- ✅ Один CSS файл с общими стилями
- ✅ Адаптивность от 1200px до 4K

### Качество кода
- ✅ Валидная верстка без нагромождений
- ✅ Отсутствует неиспользуемый код
- ✅ Нет дублирования кода
- ✅ Читаемый код с единообразными отступами (2 пробела)

### Именование
- ✅ **kebab-case** - CSS классы и HTML атрибуты (`answer-input`, `submit-button`)
- ✅ **lowercase** - стандартные HTML элементы (`div`, `button`, `input`)
- ✅ **camelCase** - JavaScript переменные и функции (`answerInput`, `toggleButtonState`)
- ✅ Английские слова без транслита и орфографических ошибок
- ✅ Переменные начинаются с существительного (`answerInput`, `submitButton`)
- ✅ Функции начинаются с глагола (`toggleButtonState`, `handleSubmit`)
