# 🎉 Весёлый тренажёр ЭМО

Интерактивный образовательный тренажёр для детей с особенностями развития.

## 📋 Описание

Яркий и дружелюбный тренажёр с озвучкой, разработанный специально для детей. Включает весёлые вопросы, крупные элементы интерфейса и мягкую женскую озвучку.

## ✨ Возможности

- 🎧 **Озвучка всех действий** мягким женским голосом
- 🎨 **Яркий дизайн** с крупными элементами
- 📱 **Адаптивность** для всех устройств (смартфоны, планшеты, ПК, 4K)
- 🎯 **5 случайных вопросов** из пула вопросов
- ✅ **Визуальная обратная связь** (анимации, цвета)
- 📊 **Таблица результатов** с детальной информацией


## 🎮 Как использовать

1. **Главная страница:**
   - Нажмите 🎧 чтобы услышать название тренажёра
   - Нажмите "НАЧАТЬ 🚀" чтобы начать

2. **Прохождение:**
   - Выберите один из 4 вариантов ответа
   - Нажмите большую круглую стрелку →
   - При правильном ответе - переход к следующему вопросу
   - При неправильном - попробуйте ещё раз

3. **Результаты:**
   - Посмотрите таблицу с результатами
   - Нажмите красный крестик ✕ для перезапуска

## 🔧 Требования

- **Браузер:** Chrome, Edge, Firefox, Safari (последние версии)
- **Озвучка:** работает лучше в Chrome и Edge
- **Интернет:** не требуется (работает офлайн)

## 🎨 Технологии

- HTML5
- CSS3 (Flexbox, Animations, Media Queries)
- JavaScript (ES6+)
- Web Speech API (для озвучки)

## 📱 Поддерживаемые устройства

- ✅ Смартфоны: Samsung A15, A55, iPhone 14, 16
- ✅ Планшеты: iPad, Android tablets
- ✅ Компьютеры: 1200px - 4K мониторы
- ✅ Ориентация: вертикальная и горизонтальная

## 🐛 Известные особенности

- Озвучка может не работать в некоторых старых браузерах
- При первом запуске может потребоваться разрешение на использование звука
- На iOS озвучка работает только после действия пользователя (нажатия кнопки)

## 🎯 Для разработчиков

### Как добавить новые вопросы:

В файле `script.js` найдите массив `QUESTIONS_POOL` и добавьте новый объект:

```javascript
{
    id: 8,
    question: "Ваш вопрос?",
    options: ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
    correctAnswer: 0, // индекс правильного ответа (0-3)
    emoji: "🌟",
    successSound: "Молодец! Это правильный ответ!"
}
```

### Как изменить количество вопросов:

В `script.js` измените константу:
```javascript
const TOTAL_QUESTIONS = 5; // измените на нужное число
```

### Как изменить цвет фона:

В `styles.css` найдите:
```css
body {
    background-color: #00D4E8; /* измените цвет */
}
```
