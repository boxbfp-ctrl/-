# Тренажер ЭМО

Интерактивный тренажер для развития ментальных навыков.

## Функциональность

- 5 случайных вопросов
- Система прогресса
- Таблица результатов
- Адаптивный дизайн
- Перезапуск тренажера

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)

## Запуск

1. Откройте `index.html` в браузере
2. Ответьте на 5 вопросов
3. Просмотрите результаты

## Структура проекта

www/
├── index.html # Главная страница с вопросами
├── results.html # Страница с результатами
├── style.css # Стили приложения
├── script.js # Логика приложения
└── README.md # Документация
